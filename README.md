# ML HW 1

פרויקט זה הוגש במסגרת מטלה בקורס למידת מכונה.

## רקע

במטלה נדרש לעבוד עם דאטהסט גדול של רכבים משומשים ולבנות תהליך מלא של למידת מכונה: טעינת הנתונים, טיפול בערכים חסרים, ניתוח חריגים, הנדסת תכונות, אימון מודלים והערכת ביצועים. מטרת הפרויקט היא לחזות את מחיר הרכב (`price` / `log_price`) ולבחון גם משימת סיווג של מצב הרכב (`condition`).

חלק מרכזי במטלה הוא מימוש עצמאי של אלגוריתמי `Decision Tree` ו-`Random Forest`, ולא רק שימוש בספריות מוכנות. לאחר המימוש, התוצאות מושוות למודלים מקבילים מ-`scikit-learn` כדי לבחון דיוק, זמני ריצה והבדלים בין מימוש ידני לבין מימושים תעשייתיים.

## תיאור הפרויקט

הפרויקט כולל מחברת Jupyter שמיישמת ומנתחת מודלים של למידת מכונה, עם דגש על:

- מימוש `Decision Tree` מאפס.
- מימוש `Random Forest` מאפס.
- תמיכה במשימות רגרסיה וסיווג.
- שימוש ב-`numpy` ו-`pandas` לעיבוד נתונים וחישובים וקטוריים.
- השוואה למודלים מוכנים מספריית `scikit-learn`.
- ויזואליזציה וניתוח תוצאות באמצעות `matplotlib` ו-`seaborn`.
