# ML HW 1

פרויקט זה הוגש במסגרת מטלה בקורס למידת מכונה.

## תיאור הפרויקט

הפרויקט כולל מחברת Jupyter שמיישמת ומנתחת מודלים של למידת מכונה, עם דגש על:

- מימוש `Decision Tree` מאפס.
- מימוש `Random Forest` מאפס.
- תמיכה במשימות רגרסיה וסיווג.
- שימוש ב-`numpy` ו-`pandas` לעיבוד נתונים וחישובים וקטוריים.
- השוואה למודלים מוכנים מספריית `scikit-learn`.
- ויזואליזציה וניתוח תוצאות באמצעות `matplotlib` ו-`seaborn`.

## קבצים בפרויקט

- `HW1_project (1).ipynb` - מחברת העבודה הראשית של המטלה.

## דרישות

כדי להריץ את המחברת יש צורך בסביבת Python עם החבילות הבאות:

- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `jupyter`

## הרצה

1. התקינו את התלויות הדרושות.
2. פתחו את המחברת `HW1_project (1).ipynb` באמצעות Jupyter Notebook, JupyterLab או VS Code.
3. הריצו את התאים לפי הסדר.

## הערה

הקוד נכתב כחלק ממטלה אקדמית ונועד להדגים הבנה של אלגוריתמים בסיסיים בלמידת מכונה ושלבי עבודה עם נתונים.
